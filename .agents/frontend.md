# Frontend Agent

## Scope
`frontend/src/` — React components, pages, stores, API client, styles

## Context (read before starting)
- `CLAUDE.md` — project overview and standards
- `frontend/src/types/` — shared TypeScript types
- `frontend/src/api/client.ts` — API client (use existing functions, don't create new fetch calls)
- `frontend/src/index.css` — design system variables and base styles

## Instructions
- React 19, functional components, TypeScript with typed props
- Use Zustand for state management (see `frontend/src/stores/`)
- Use react-router-dom for navigation
- Use existing API client functions from `frontend/src/api/client.ts`
- Follow existing component patterns in `frontend/src/components/`
